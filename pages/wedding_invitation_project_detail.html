01 / Visión General

Propósito del Proyecto

Las invitaciones tradicionales impresas a menudo carecen de interactividad y dificultan la gestión centralizada de asistencia. Este proyecto consiste en una aplicación web interactiva desarrollada con Flask y SQLite, diseñada para transmitir la calidez de un evento de boda, mostrar detalles del evento e interactuar de forma intuitiva con los invitados.

Para brindar una experiencia inmersiva y emotiva, la aplicación integra la librería de JavaScript particles.js que le da vida al fondo con movimiento fluido de partículas, complementado con la incorporación de sonido ambiental que envuelve al invitado en una atmósfera elegante desde el momento en que abre la invitación web.

Además, la plataforma integra un formulario de confirmación en tiempo real que captura los datos de los asistentes, realiza validaciones en la base de datos para evitar registros duplicados por nombre y responde con vistas dinámicas personalizadas.

02 / Arquitectura & Datos

Esquema de Base de Datos & Reglas de Negocio

La persistencia de datos se gestiona a través de SQLite.

01
Ruta Principal ("/")
Renderiza la vista principal `index.html` integrando el lienzo interactivo de partículas mediante `particles.json` y la tarjeta con el formulario de confirmación.
02
Endpoint de Confirmación ("/confirmar")
Recibe peticiones HTTP POST con el nombre, estado de asistencia y mensaje opcional. Consulta la base de datos previa a la inserción para verificar existencia.
03
Control de Duplicados & Respuestas Dinámicas
Si el invitado ya se encuentra registrado en la tabla `invitados`, la aplicación renderiza `confirmado.html`. De lo contrario, registra la asistencia y redirige a `gracias.html`.
