Sitio web de portafolio profesional interactivo, desarrollado desde cero con Vanilla HTML5, CSS3 modular y JS. Integrado con EmailJS para el envío automatizado de mensajes de contacto directamente desde el cliente.

Destacado HTML5 / CSS3 Vanilla JS EmailJS Responsive
